# 🏥 Clínica Vida+

Site institucional desenvolvido para uma **clínica médica multidisciplinar**, com foco em apresentar os serviços, especialidades, equipe profissional, estrutura e canais de contato de forma moderna, elegante e responsiva.

> ⚠️ **PROJETO DEMONSTRATIVO**
>
> Este site foi desenvolvido exclusivamente para fins de demonstração e portfólio.
> A Clínica Vida+, os profissionais, endereço, contatos, horários e demais informações apresentadas são fictícios.

🔗 **Link do site:** https://mil786.github.io/clinica-Vida/

## 📌 Sobre o projeto

O projeto apresenta uma landing page/site institucional para uma clínica médica fictícia, utilizando uma identidade visual sofisticada, moderna e acolhedora.

A proposta foi criar uma experiência profissional tanto para computadores quanto para dispositivos móveis, utilizando uma estrutura organizada, navegação simples e chamadas para ação direcionadas ao contato com a clínica.

## 🩺 Especialidades

O site apresenta algumas das principais especialidades disponíveis na clínica:

- Clínica Geral
- Cardiologia
- Pediatria
- Ortopedia
- Dermatologia
- Psiquiatria
- Nutrição
- Fisioterapia

As especialidades são carregadas dinamicamente através do JavaScript.

## 👩‍⚕️ Equipe profissional

A página possui uma seção dedicada aos profissionais da clínica, apresentando:

- Nome
- Especialidade
- Foto
- Breve descrição profissional

Os profissionais apresentados no projeto são fictícios e utilizados exclusivamente para fins demonstrativos.

## 🤖 Imagens geradas por IA

> ⚠️ **Aviso importante sobre as imagens**

As imagens utilizadas para representar os médicos e profissionais da Clínica Vida+ foram **geradas utilizando Inteligência Artificial (IA)**.

As pessoas apresentadas nas imagens **não representam profissionais reais da clínica** e não devem ser interpretadas como pessoas reais vinculadas à Clínica Vida+.

As imagens possuem finalidade exclusivamente visual e demonstrativa para este projeto.
